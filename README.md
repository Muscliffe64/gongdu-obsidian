# 共读打卡 · Obsidian 插件

给在 Obsidian 里用 [Qiaomu Reader](https://github.com/joeseesun/qiaomu-reader)（乔木阅读器）读电子书的学生用。读书时阅读器记下的时长、进度和高亮，在这里一屏打卡到班级的[共读](https://github.com/Muscliffe64/gongdu)网站；打开一本书时，自动把阅读器里的封面同步到共读书架上的同一本书。

它不是 Qiaomu Reader 的改版：Qiaomu Reader 照常用、照常更新，这个插件只读它记下的数据，不改它的任何文件。

## 学生怎么用

1. 装好 Qiaomu Reader 和本插件（见下面「安装」）。
2. 在共读网站“我的”页面点「连接 Obsidian」，Obsidian 会打开并问一句要不要连，点「连接」就好（网站拿一次性连接码，插件用它换令牌，不用复制粘贴）。Obsidian 在另一台设备上时，把网站上显示的连接码填在设置 → 共读打卡 →「连接共读」里。
3. 读书。时间自动记（见下面「自动计时」）。读到想摘的句子，选中它点左边栏的共读按钮（或者「摘下选中的句子」命令），先摘下来。
4. 读完点左边栏的「共读：读书打卡」按钮（或者命令面板里的「读书打卡」，或者状态栏上的“共读 · …”）。

打卡窗口一屏：

- **书**：自动对到共读书架上的书（按书里写的书名、文件名，以及以前打卡时确认过的）。书架上没有就是「加一本：《…》」，打卡时网站会加上。
- **今天读了几分钟**：插件今天自动给这本书记的分钟（网站上这本书今天已经交过更多的，就填那个，不往少里改）。插件没记到时，退回用 Qiaomu Reader 自己的计时（要在阅读器菜单里手动开始）：它记的是所有书一起的，今天别的书已经记过的会减掉，这本书已经记过的会保留（网站上同一本书再交是覆盖）。
- **读书时摘的**：读书时摘下的句子，默认勾上，每句可以加想法，也可以“不要这句”。摘的时候顺手记下第几章第几节（从书的目录读；目录只到章的书，再接上选中那段前面最近的小节标题），电子书自带纸书页码表的还会带上页数；两格都可以改。书里的公式（图片里写着 LaTeX 的，或者 MathML）摘下来写成 `$…$`、单独一行的写成 `$$…$$`，分段留着；打卡窗口和共读网站上都显示成公式。打卡交上去以后就从本机去掉；不是今天的也去掉。
- **读到百分之几**：阅读器里这本书的进度。
- **今天的高亮**：勾上想摘的句子，每句可以加想法。高亮的文字是 Qiaomu Reader 自己存的，里面的公式会丢；带公式的句子用上面的“选中再点共读按钮”来摘。书开着时按高亮记的位置填上第几章第几节。有摘的或高亮时，「自己再写一句」先收起来。今天还没有摘录时至少要有一句。
- **换成阅读器里的封面**：只有网站上这本书已经有封面图（或者去掉过）、而阅读器里找得到封面时才出现，默认不勾。

## 自动计时

Qiaomu Reader 自己的计时要在阅读器菜单里手动点开始，大多数人找不到，所以插件自己记，不用点开始、停止。每 15 秒看一次，这三条都满足才把这段时间记到正在读的书上：

1. 当前标签页是 Qiaomu Reader 里的一本书；
2. Obsidian 在最前面（窗口有焦点、没被藏起来）；
3. 最近 3 分钟里点过、按过键、滚过、动过鼠标、选过字，或者阅读器的进度变了（翻页）。右边栏的 AI 伴读也算在这本书上。
   3 分钟没动先暂停；离上次动作 8 分钟之内又动了，而且中间书一直开着、Obsidian 一直在最前面、打卡窗口没开，停下的那段补回来（读难的一页、读 AI 伴读的长回答时不碰鼠标键盘也算）。

打卡窗口开着的时候不算。电脑睡眠回来，两次检查之间最多补 30 秒。

**看得见的计时**：状态栏常驻一行“共读 · 计时中 / 已暂停 · 《书名》 N 分钟 · 今天打过卡没有”，前面的图标也分计时中（计时器图标、强调色）和已暂停（暂停图标、次要色），悬停看暂停的原因和怎么接着记，点一下打开打卡窗口。Qiaomu Reader 读书时会把状态栏藏起来，所以左边栏的共读按钮上也标这本书今天的分钟数（计时中是强调色，暂停是灰的），悬停看同样的说明。

**分钟先填多少**（`src/checkin-logic.js` 的 `minutesPlan`）：只有下拉框选的正是阅读器里这个文件对应的书时，才用插件的时间：网站上这本书今天已经记的 + 插件记了还没交过的。选了别的书，插件的时间不算，说明里会讲。插件没记到时，退回 Qiaomu Reader 自己的计时；都没有就空着（网站上这本书今天已经记过就填那个），下面用次要色小字说明为什么、怎么会自动记，不当成错误。

**交上去以后算交过多少**（`Clock.committedAfter`）：交的分钟数先算网站上原来的，多出来的才是插件的时间；多出来的不少于没交过的插件分钟，就全部算交过；学生往少里改了，只算多出来的那几分钟，剩下的下次还会加上；没多出来就一点也不算。

**检查**：只在点「打卡」时检查。分钟数 1–1440 的整数、读到 0–100，全角数字也认；不对就在那一栏下面说怎么改，输入框标红并获得焦点，一改就消掉。按书、按本机日期记在插件数据里（只留最近 3 天）；书改名、挪位置，时间跟过去。

书的内容在 foliate-js 的 closed shadow DOM 里的 iframe 里，外面收不到里面的事件，也拿不到选中的文字。插件通过 foliate-view 元素公开的 `renderer.getContents()` 拿到正在显示的 document，在里面挂监听、读选区（`src/reader-dom.js`），只看不改。

## 用起来的流程（0.3.0）

目标：读书时不打扰，读完一次确认。

- **摘句不打断**：Qiaomu Reader 里画的高亮在打卡窗口里默认勾上；左边栏共读按钮在书里选中了新的一句时只摘下来（右上角提示几秒），不打开窗口；没选中、或者这句已经摘过，才打开打卡窗口（`ribbonAction`）。
- **打卡窗口是确认，不是填表**：最上面一行“《书》 · N 分钟 · 读到 P%  改”，书、分钟、进度默认收起来；拿不准时（没找到书、分钟不是插件计时来的或没有、没有进度、新书没书名）一打开就展开并说为什么（`detailReasons`）。光标放在第一句的想法框里（拿不准时放在要看的那一栏），Cmd/Ctrl+Enter 打卡；打好了、没有要看一眼的事（还有句子没交、高亮超了、封面没换成）就 3 秒后自己关上（`canAutoClose`）。
- **读完提醒**：从一本书离开、现在没在读别的书，这本书今天插件计了 10 分钟以上、今天还没打卡（先问一次网站）、今天还没提醒过，就在右上角提醒一句，带“打卡”按钮，15 秒后消失（`shouldRemind`）。

## 封面怎么同步

打开一本书（在 Qiaomu Reader 里）一两秒后，插件在后台：

1. 问共读网站书架上有哪些书（两分钟内用缓存），对到这本书。**书架上没有就不传**，只给个提示。
2. **网站上已经有封面图就不换**；本人或老师去掉过封面图的也不再自动传。
3. 按这个顺序找封面：书的笔记里写的 `cover:` → 书里自带的封面（EPUB）→ Qiaomu Reader 的封面缓存。
   Qiaomu Reader 在书里没有封面时会用书名画一张文字封面，**这种不传**（网站有自己的文字封面）。
4. 缩到 480×720 以内、280 KB 以内的 JPEG，传上去。
5. 找不到封面就什么也不说，一天内不再找（换了文件马上再试）；图片不收（比如形状不像封面）的，这个文件不再试；断网、服务器出错的，一天后再试。

**安静**：不弹窗。有提示或出了问题，状态栏写一句（一分钟后消掉），左边栏的「共读」按钮上标一个小点（提示是蓝的，出错是红的），打开打卡窗口时最上面会说是什么，小点就消掉了。
之所以还要小点：Qiaomu Reader 读书时会把 Obsidian 的状态栏藏起来，只写在状态栏上读书时看不到。iPad 上的 Obsidian 本来就没有状态栏。

命令面板里还有「再试一次同步这本书的封面」：忘掉这本书传没传过，马上再试一次。

## 读的是哪些数据

依据 Qiaomu Reader 4.9.x 的源码，都是只读：

| 什么 | 在哪里 |
|---|---|
| 今天读了多久 | Qiaomu Reader 插件数据 `data.json` 的 `settings.readingLog["YYYY-MM-DD"]`（秒，所有书一起） |
| 读到哪里 | `<数据文件夹>/reading-progress.json`：`{ 书的路径: { pct, percent, lastRead } }` |
| 高亮 | `<数据文件夹>/reading-highlights.json`：`{ 书的路径: [ { text, created, cfi } ] }` |
| 读到哪一章 | 阅读页里的 `<…foliate-view>` 元素：`book.toc`（目录）、`book.resolveHref`、`lastLocation`（`section.current`、`tocItem`、`pageItem`）、`resolveCFI`。只读 |
| 封面缓存 | `.obsidian/plugins/qiaomu-reader/thumbnails-v3/<sha256(JSON.stringify([路径, mtime, size]))>.jpg`，书在 Qiaomu Reader 书库里显示过才有 |
| 书的笔记 | `settings.bookNoteLinks[书的路径]`，笔记属性 `cover:`（图片链接或网址） |

数据文件夹 = Qiaomu Reader 设置里的「数据文件夹」，空着就是「书的文件夹」，再空就是库的根目录。Qiaomu Reader 开着时直接读它内存里的数据（最新），读不到再读文件。

Qiaomu Reader 的阅读页不算 Obsidian 的“当前文件”，打开书时没有 `file-open` 事件，所以插件看的是当前标签页里的 `view.file`（`active-leaf-change`、`layout-change`）。

## 安装

还没上架 Obsidian 社区插件。两种装法：

- **BRAT**（推荐）：装 BRAT 插件 → Add Beta plugin → 填 `Muscliffe64/gongdu-obsidian`。给学生的完整步骤见 [INSTALL.md](INSTALL.md)。
- **手动**：把这三个文件放进库里的 `.obsidian/plugins/gongdu/`，在设置 → 第三方插件里打开「共读打卡」。

## 开发

不用第三方依赖，Node 22 以上。

```bash
node build.js              # 把 src/ 打成 main.js
node build.js <库的路径>    # 同时装到那个库的 .obsidian/plugins/gongdu/
npm test                   # node:test；cover-sync 的测试会起一个本机的共读服务器（../gongdu，或 GONGDU_DIR）
```

| 文件 | 做什么 |
|---|---|
| `src/main.js` | 插件本身：状态栏、命令、左边栏按钮、设置页、打开书时触发同步、自动计时、摘句、`obsidian://gongdu-connect` 连接窗口 |
| `src/clock.js` | 自动计时的规则（什么时候算在读、为什么暂停、按书按天记、交过多少） |
| `src/timer-view.js` | 状态栏和左边栏按钮上的计时显示 |
| `src/checkin-logic.js` | 打卡窗口里分钟先填多少、检查填的数、这次带上几句 |
| `src/clips.js` | 读书时摘下的句子：去重、按书按天、交上去以后去掉 |
| `src/place.js` | 摘句在第几章第几节、第几页：从书的目录和 foliate 的 lastLocation 读，摘句按选区位置找，高亮按 cfi 找 |
| `src/mathtext.js` | 书里的公式（图片 alt、MathML）读成 `$…$`；和共读网站的 `web/js/mathtext.js` 是同一份 |
| `src/reader-dom.js` | 进到阅读页里：挂监听看有没有在读（插件关掉时撤下），读选中的文字 |
| `src/connect.js` | 用连接码换令牌，检查网站地址（只收 https 和本机） |
| `src/checkin-modal.js` | 打卡窗口 |
| `src/cover-sync.js` | 自动同步封面的规则（不碰 Obsidian，测试里换成假的） |
| `src/obsidian-io.js` | 读 Qiaomu Reader 的数据、找封面、缩成 JPEG |
| `src/qiaomu.js` | Qiaomu Reader 数据的格式和路径 |
| `src/epub.js` | 从 EPUB 里取书名、作者、封面（自己读 zip，用 DecompressionStream 解压） |
| `src/generated-cover.js` | 认出 Qiaomu Reader 自己画的文字封面 |
| `src/match.js` | 把阅读器里的书对到共读书架上的书 |
| `src/api.js` | 共读网站的智能体接口 |

### 发布新版本

改 `manifest.json` 的 `version`，在 `versions.json` 里加一行，合并到 `main` 以后推一个**同名、不带 v** 的标签（比如 `0.1.1`）。GitHub Action（`.github/workflows/release.yml`）会跑测试、打包，发布 Release 并附上 `main.js`、`manifest.json`、`styles.css`。

### 在真的 Obsidian 里试

`scripts/make-test-vault.js` 建一个测试库（装好 Qiaomu Reader、本插件和三本测试 EPUB），`scripts/obsidian-e2e.mjs` 用单独的用户数据目录起一个 Obsidian（不碰自己平时用的库和设置），用 DevTools 协议一步步操作、截图。用法写在两个脚本开头。
